#  API REST de Gerenciamento de Livros

Uma API RESTful simples desenvolvida em **Python** utilizando o framework **Flask** para gerenciamento de livros. O projeto realiza todas as operações básicas de um CRUD (Create, Read, Update, Delete) manipulando dados em memória.

---

##  Tecnologias Utilizadas

- **Python 3**
- **Flask**
